# Idle Babel

> *Un chercheur solitaire, piégé à jamais au cœur de la Bibliothèque de Babel,
> tourne des pages de non-sens pour y trouver le sens de sa vie.*

**Jouer :** https://counteraccro.github.io/IdleBabel/

Idle Babel est un jeu *idle* (incrémental) pour navigateur, inspiré de la nouvelle
*La Bibliothèque de Babel* de Jorge Luis Borges : une bibliothèque infinie qui contient
tous les livres possibles de 410 pages. Le joueur lit, page après page, dans l'espoir d'y
trouver quelques phrases qui ont un sens.

> 🤖 **Ce jeu est généré par [Claude Code](https://claude.com/claude-code)**, l'assistant de
> programmation d'Anthropic. Le code, la conception détaillée, l'équilibrage et les
> simulations ont été produits par Claude Code, sous la direction de l'auteur du projet
> ([@counteraccro](https://github.com/counteraccro)), qui a imaginé l'univers, l'histoire et la
> direction artistique, et généré les illustrations.

## Ce qu'on y trouve (prototype en cours)

- **Un livre tenu en main** : chaque clic tourne une page. Un appui maintenu permet de tenir la
  page et de la tourner soi-même à la souris ou au doigt. La page est simulée en WebGL : le papier
  s'enroule comme une vraie feuille.
- **Le texte de Babel** : les pages sont écrites avec les 25 symboles de la nouvelle de Borges.
  De temps en temps, une phrase sensée apparaît au milieu du non-sens, surlignée.
- **Un décor peint qui se révèle** : le chercheur se réveille dans l'obscurité et découvre sa
  pièce au fil de sa lecture. Une fois vue, il ne l'oublie plus.
- **Un faux dehors** derrière l'unique fenêtre, animé en profondeur.
- **Les méthodes de lecture** : des outils qui lisent pour vous (la Lecture Diagonale…).
- **Français et anglais**, sauvegarde automatique dans le navigateur.

La suite (les cinq Âges, le journal de bord, la Connaissance, l'Exil, les futurs…) est en conception.

## Technique

| | |
| :--- | :--- |
| Langage | TypeScript |
| Outil de build | [Vite](https://vite.dev) |
| Rendu | DOM + WebGL 2 (décor en profondeur, page qui tourne) |
| Tests | [Vitest](https://vitest.dev) |
| Déploiement | GitHub Actions → GitHub Pages, à chaque push sur `main` |

Aucun serveur : le jeu est un ensemble de fichiers statiques, et la sauvegarde est dans le
`localStorage` du navigateur.

### Lancer le projet

```bash
npm install
npm run dev      # jeu en local : http://localhost:5173/IdleBabel/
npm test         # tests (formules, traductions, texte de Babel…)
npm run build    # version de production dans dist/
```

### Mode débogage

Ajouter `?debug` à l'adresse (en local comme en ligne) ouvre un panneau pour régler à la volée
les pages en stock et les pages lues à vie.

### Organisation

```
src/
  core/      état du jeu, boucle, sauvegarde, historique de partie
  data/      contenu chiffré (outils…), sans texte
  systems/   règles : production, clic, perception de la pièce, texte de Babel, fragments
  scene/     décor peint en WebGL (carte de profondeur, obscurité, faux dehors)
  ui/        interface ; ui/book/ : le livre et la page qui tourne
  i18n/      textes, un dossier par langue (fr/, en/)
  debug/     panneau de débogage
public/scenes/  illustrations et cartes de profondeur utilisées par le jeu
tests/
```

Un fichier par fonctionnalité. Tous les textes passent par `src/i18n/` ; un test vérifie que
chaque langue a exactement les mêmes clés que le français.

### Ajouter une langue

Copier `src/i18n/fr/`, traduire les fichiers JSON, puis déclarer la langue dans
`src/i18n/locales.ts`.

## Illustrations

- Générées par l'auteur avec [Draw Things](https://drawthings.ai) et le modèle RealVisXL,
  puis agrandies ×2.
- Cartes de profondeur produites avec [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2).
