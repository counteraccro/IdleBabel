# Attrape-lettres / Letter catcher

Chaque lettre qui s'échappe du livre est attrapée toute seule, une seconde après avoir paru, les lettres du mot BABEL
comprises. Crochet : `letter` (`catch()`).

Every letter escaping the book is caught on its own, one second after it appears, the letters of the word BABEL included.
Hook: `letter` (`catch()`).
