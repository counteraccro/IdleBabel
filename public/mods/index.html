Idle Babel — Mods

Un mod change un morceau du jeu : il lit plus vite, chasse la Mimic, attrape les lettres, ajoute des sceaux… Cette page explique comment en écrire un, le charger, et le proposer pour la liste du jeu.

Un premier mod

Un mod est un fichier JavaScript. Il s’enregistre auprès du jeu par IdleBabel.registerMod, puis se branche sur ses crochets : des moments du jeu où il est appelé. Celui-ci double la lecture de toutes les méthodes : 

IdleBabel.registerMod('double-lecture', {
  version: '1.0.0',
  init() {
    // À chaque calcul de la production : ×2.
    IdleBabel.registerHook('reading', () => 2);
    IdleBabel.notify('Double lecture', 'Les méthodes lisent deux fois plus vite.');
  },
});

Enregistrez-le sous double-lecture.js, mettez-le en ligne (voir plus bas), et chargez-le dans le jeu.

Le charger

Dans le jeu, ouvrez le cahier d’options, page Mods (après la Sauvegarde). « Liste des mods » montre ceux du jeu, avec leur description : « Ajouter » en prend un. Pour un autre, « Ajouter un mod par son adresse » et collez son adresse, par exemple : 

https://counteraccro.github.io/IdleBabel/mods/sans-mimic/sans-mimic.js

Le mod se charge aussitôt, puis à chaque visite, dans l’ordre où ils ont été ajoutés ; il apparaît sur la page Mods. Sa case décochée le désactive (il reste dans la liste, il n’est plus chargé) ; « supprimer » l’enlève. L’un comme l’autre recharge la page : un mod en code ne se défait pas en cours de partie. La liste est gardée dans la sauvegarde (et dans son export).

Pour essayer pendant que vous écrivez, la console du navigateur suffit : IdleBabel.loadMod('https://…').

L’héberger

Il faut une adresse qui serve le fichier comme du JavaScript (ou du JSON). Ce qui marche :

  • GitHub Pages : un dépôt avec Pages activé, le fichier à la racine : https://votre-nom.github.io/votre-depot/mon-mod.js.
  • jsDelivr, devant un dépôt GitHub public, sans rien configurer : https://cdn.jsdelivr.net/gh/votre-nom/votre-depot/mon-mod.js.
  • Un Gist : jsDelivr ne sert que les dépôts ; pour un Gist, passez plutôt par un dépôt.
Les adresses « raw » de GitHub (raw.githubusercontent.com, gist.githubusercontent.com) servent le fichier comme du texte : le navigateur refuse de l’exécuter. Elles marchent pour un mod .json, pas pour un .js.

L’API : window.IdleBabel

NomCe qu’il fait
registerMod(nom, { version, init, save, load, options, onOptions }) Enregistre le mod. version : une chaîne (« 1.0.0 »), montrée au cahier à côté de son nom. init() : une fois, au chargement ; c’est là qu’on pose ses crochets. save() : rend une chaîne, gardée dans la sauvegarde du jeu. load(texte) : appelé juste après init, avec ce que save() avait rendu la dernière fois. options et onOptions : voir les options. Tous sont facultatifs. Rend false si le nom est vide ou déjà pris.
registerHook(crochet, fonction)Branche une fonction sur un crochet.
stateLa partie, lisible et modifiable (voir plus bas).
notify(titre, texte)Une annonce en bas de l’écran, qui s’efface seule (du texte, pas de HTML).
addSeal({ id, name, text, reached }) Un sceau à vous, sur une planche « Mods » du livre étrange. name et text : une chaîne, ou { fr, en }. reached(state) : rend true quand il est atteint (regardé à chaque pas du jeu). Il prend le nom du mod qui l’ajoute : appelez-le dans init.
format(nombre)Un nombre écrit dans la notation choisie par le joueur (« 1,23 million »…).
localeLa langue du jeu : 'fr' ou 'en'.
gameCe que le jeu calcule (production, prix, Éther, lettre, Mimic), en lecture seule : voir plus bas.
option(mod, id)La valeur d’une option d’un mod, réglée au cahier (les options) ; undefined si elle n’existe pas.
loadMod(adresse)Charge un autre mod (rend une promesse : true s’il a chargé).
replaceHeldBook(book => ({ root, update })) Remplace le livre ouvert en bas de l’écran par votre vue (root, un élément HTML), au même endroit. Le jeu garde le rythme des pages, les trouvailles et la fin du livre ; update() est appelé à chaque feuille tournée, à la main ou seule. book : index (le n° du livre), page (la feuille ouverte montre page et page + 1 ; 0 : le livre vient d’arriver), pages (410), title, text(page) (rend { before, find, after } : find, la trouvaille, ou vide) et turn() (tourne une feuille, comme un clic). Livres ordinaires seulement : un livre rare et le Grand Livre restent en 3D. Un seul remplaçant, le dernier. Exemple : la liseuse.

Un mod qui lève une erreur ne fait pas planter le jeu : l’erreur s’écrit dans la console, ce crochet-là est sauté, le reste continue.

Les crochets

IdleBabel.registerHook(nom, fonction) ; plusieurs mods peuvent se brancher sur le même crochet.

CrochetQuandLa fonction reçoitElle rend
tick À chaque pas de la boucle de jeu (dix par seconde ; une par seconde, onglet caché). Les secondes écoulées. —
draw Après chaque mise à jour de l’écran (onglet visible seulement). — —
reading À chaque calcul de la production. — Un multiplicateur de la lecture de toutes les méthodes (2 : deux fois plus).
click Une feuille tournée à la main. — Un multiplicateur des pages de ce clic.
find Une trouvaille lue (dans le livre en main, ou pendant une absence). { kind, text, duplicate } : kind vaut 'word', 'piece' ou 'sentence' ; duplicate, un morceau déjà écrit. —
prestige Juste après un prestige (« Le nourrir »). — —
reset La sauvegarde effacée, juste avant que la page se recharge. — —
mimic Une Mimic va apparaître. — false pour l’en empêcher (rien, ou autre chose : elle vient).
letter Une lettre vient de s’échapper du livre. { id, glyph, catch() } : id vaut 'letter' (un bonus) ou 'word' (une lettre du mot BABEL) ; catch() l’attrape, comme un clic dessus. —

Les options d’un mod

Un mod déclare ses options dans registerMod ; le jeu leur dessine une page du cahier, juste après les pages « Mods » (une par mod actif qui en a), les garde dans la sauvegarde (export compris) et prévient le mod quand elles changent. Le sommaire, en première page du cahier, y mène. Rien à écrire pour le cahier. 

IdleBabel.registerMod('mon-mod', {
  version: '1.0.0',
  options: [
    // Un choix parmi plusieurs : le choisi est entouré au stylo.
    { id: 'taille', name: { fr: 'Taille', en: 'Size' }, default: 'grand',
      choices: [{ id: 'petit', name: { fr: 'Petit', en: 'Small' } }, { id: 'grand', name: { fr: 'Grand', en: 'Large' } }] },
    // Sans choices : une case à cocher (default true ou false), avec sa ligne au crayon.
    { id: 'bloc', name: { fr: 'Le bloc', en: 'The block' }, hint: { fr: 'En bas à gauche.', en: 'Bottom left.' }, default: true },
    // needs : grisée tant que la case « bloc » est décochée.
    { id: 'heure', name: { fr: 'L’heure', en: 'The time' }, default: true, needs: 'bloc' },
  ],
  // Après init et load, avec toutes les valeurs ; puis à chaque changement au cahier.
  onOptions(valeurs) { console.log(valeurs.taille, valeurs.bloc); },
});
IdleBabel.option('mon-mod', 'taille');   // 'grand' : la valeur, n'importe quand

name, hint et le nom d’un choix : une chaîne, ou { fr, en }. Une valeur gardée qui ne vaut plus rien (option retirée, choix renommé) reprend son défaut ; une option mal formée est sautée (dit dans la console). La page a le nom du mod, sa version, puis chaque option dans l’ordre déclaré.

Ce que calcule le jeu : IdleBabel.game

Les vraies formules du jeu, en lecture seule : un mod qui montre des chiffres les demande ici plutôt que de les recopier (elles changent à chaque rééquilibrage). Rien ici ne modifie la partie. Les noms sont dans la langue du jeu.

FonctionCe qu’elle rend
methods()Chaque méthode : { id, name, owned, visible, nextCost, rate }. visible : retrouvée, son sceau est dans la ruche ; nextCost : le prix du prochain exemplaire (Économie du geste et bonus en cours compris) ; rate : les pages par seconde d’un exemplaire de plus.
pagesPerSecond()La production, en pages par seconde.
intuitions()Chaque intuition du livre blanc : { id, name, level, maxLevel, nextPrice, visible, method }. nextPrice : en Connaissance, undefined au bout ou tant qu’elle ne peut pas se comprendre ; maxLevel : Infinity si elle est sans fin ; method : l’id de la méthode qu’elle double à chaque niveau, sinon null.
letterIn()Les secondes avant la prochaine lettre, ou undefined tant qu’elle n’est pas tirée. Le compte ne descend qu’à l’écran du jeu.
mimic(){ unlocked, here, every } : débloquée, là en ce moment, et toutes les combien de secondes en moyenne. Elle n’a pas d’heure : chaque seconde, une petite chance.
ether(){ gain, total, next } : l’Éther que rapporterait le prestige maintenant, les pages lues depuis toujours, et celles qu’il faut pour un Éther de plus.

Chaque sceau de la ruche porte data-method="<id>" : un mod sait quel hexagone est quelle méthode. Le jeu ne touche à aucun autre attribut data-* d’un sceau : un mod peut y écrire.

La partie : IdleBabel.state

Tout l’état de la partie, tel qu’il est sauvegardé. On peut le lire, et le modifier, à ses risques : le jeu ne vérifie rien. Les champs les plus utiles :

ChampCe que c’est
pagesLes pages en réserve (celles qu’on dépense).
totalPagesReadLes pages lues depuis toujours (ne baisse jamais).
toolsLes méthodes possédées : { diagonal: 12, finger: 3, … }.
knowledge, lifetimeKnowledgeLa Connaissance à dépenser ; celle trouvée depuis toujours.
ether, etherReceivedL’Éther à dépenser ; celui reçu depuis toujours.
booksFinished, bookPageLes livres lus jusqu’au bout ; la page du livre en main.
stats.clicks, stats.playSecondsLes feuilles tournées à la main ; le temps de jeu, en secondes.
exilesLes prestiges faits.
sealsLes sceaux obtenus, avec leur date.
settingsLes réglages du cahier d’options.
mods, modDataLes adresses des mods chargés ; ce que chacun a sauvegardé.

Pour garder des données à vous, passez par save / load plutôt que d’ajouter des champs.

Les mods sans code (.json)

Un fichier .json ne contient que des données : il ne peut rien faire d’autre que ce que le jeu prévoit, il est donc sans risque. Pour l’instant, il ajoute des sceaux, chacun atteint quand un compteur du jeu arrive à sa valeur : 

{
  "id": "mon-mod",
  "version": "1.0.0",
  "seals": [
    {
      "id": "million",
      "name": { "fr": "Un million", "en": "One million" },
      "text": { "fr": "Lis un million de pages", "en": "Read a million pages" },
      "when": { "pagesRead": 1000000 }
    }
  ]
}

Les compteurs : pagesRead (depuis toujours), booksRead, clicks, knowledge (depuis toujours), ether (reçu), playSeconds, prestiges. Plusieurs dans when : il les faut tous.

Les sceaux des mods sont sur leur propre planche, à la fin du livre étrange. Ils ne comptent ni dans l’avancement du livre ni dans le bonus de trouvailles (+1 % par sceau) : un mod ne fausse pas la partie par là.

Les mods du jeu, commentés

Sans Mimic — sans-mimic.js

// Le nom du mod : celui qu'affiche le cahier, et la clé de ses données.
IdleBabel.registerMod('sans-mimic', {
  version: '1.0.0',
  // Appelé une fois, au chargement.
  init() {
    // Juste avant qu'une Mimic apparaisse, le jeu demande : rendre false l'en empêche.
    IdleBabel.registerHook('mimic', () => false);
  },
});

Une Mimic déjà là reste : attrapez-la, elle rend ce qu’elle a avalé.

Attrape-lettres — attrape-lettres.js

IdleBabel.registerMod('attrape-lettres', {
  version: '1.0.0',
  init() {
    // Chaque lettre qui s'échappe du livre arrive ici.
    IdleBabel.registerHook('letter', (letter) => {
      // On la laisse monter une seconde, puis on l'attrape, comme d'un clic.
      setTimeout(() => letter.catch(), 1000);
    });
  },
});

Les lettres du mot BABEL aussi : le mot s’écrit en entier.

Liseuse — liseuse.js

IdleBabel.replaceHeldBook((book) => {
  // La vue : un écran, et sa moitié droite qui tourne la feuille.
  const root = document.createElement('div');
  const next = document.createElement('div');
  next.addEventListener('click', () => book.turn());
  // Une page : son charabia, sa trouvaille soulignée (en texte, jamais en HTML).
  const paragraph = (page) => {
    const { before, find, after } = book.text(page);
    const p = document.createElement('p');
    p.append(before, ' ', Object.assign(document.createElement('u'), { textContent: find }), ' ', after);
    return p;
  };
  // Appelé à chaque feuille tournée : on réécrit l'écran.
  const update = () => root.replaceChildren(paragraph(book.page), paragraph(book.page + 1), next);
  update();
  return { root, update };
});

Le vrai fichier ajoute le boîtier, le titre, « Pages 12–13 sur 410 », la barre de progression, la page de titre d’un livre neuf, et une police qui rapetisse pour que les deux pages tiennent dans l’écran.

BetterBabel — better-babel.js

Des aides de lecture, comme Cookie Monster pour Cookie Clicker : chaque méthode de la ruche prend la couleur de son rang, et un bloc en bas à gauche dit la prochaine lettre, la Mimic, le prochain Éther, les intuitions à s’offrir. Ses neuf options ont leur page au cahier. Les passages clés : 

// Le rang d'une méthode : attente + remboursement d'un exemplaire, le plus petit gagne.
const production = IdleBabel.game.pagesPerSecond();
const score = (m) => Math.max(0, m.nextCost - IdleBabel.state.pages) / production + m.nextCost / m.rate;
const ranked = IdleBabel.game.methods().filter((m) => m.visible).sort((a, b) => score(a) - score(b));
// La couleur : un attribut à lui sur le sceau, et ses styles (le jeu n'y touche pas).
for (const seal of document.querySelectorAll('.method-seal[data-method]'))
  seal.dataset.betterRank = ranked.findIndex((m) => m.id === seal.dataset.method);
// Le prochain Éther : les pages qui manquent ÷ le rythme de la dernière minute.
const { total, next } = IdleBabel.game.ether();
// La Mimic n'a pas d'heure : sa moyenne, et la chance de la voir d'ici 10 min.
const { every } = IdleBabel.game.mimic();
const chance = 1 - Math.exp(-600 / every);

Le bloc est posé dans le pied de l’écran (crochet draw, une fois par seconde) ; le rythme se mesure au crochet tick, onglet caché compris. Ses limites : le rang vaut pour un exemplaire, même en lot ×10 ; il ignore ce qu’un achat débloque sans pages (la phrase à 25 exemplaires, les sceaux).

Un mod qui garde des données

let mots = 0;
IdleBabel.registerMod('compte-mots', {
  version: '1.0.0',
  init() {
    IdleBabel.registerHook('find', (find) => {
      if (find.kind === 'word') mots += 1;
    });
    IdleBabel.addSeal({
      id: 'cent-mots',
      name: { fr: 'Cent mots', en: 'A hundred words' },
      text: { fr: 'Trouve cent mots avec ce mod', en: 'Find a hundred words with this mod' },
      reached: () => mots >= 100,
    });
  },
  // Gardé dans la sauvegarde du jeu, rendu à load() à la visite suivante.
  save: () => String(mots),
  load: (texte) => { mots = Number(texte) || 0; },
});

Ce qu’un mod change à la partie

Au premier mod chargé, la partie est marquée, pour toujours, même si le mod est retiré ensuite. Rien d’autre : le jeu continue comme avant. Où cela se voit, c’est à vous de le trouver.

Un mod en code peut tout faire : changer la partie, la casser, lire ce que la page affiche. Ne chargez que des mods de confiance, ceux de la liste du jeu (relus avant d’y entrer) ou ceux dont vous avez lu le code.

Proposer un mod pour la liste du jeu

Les mods de la liste s’ajoutent depuis le cahier, sans adresse à coller : ils sont servis par le jeu lui-même. Pour y proposer le vôtre, ouvrez une pull request sur le dépôt du jeu avec :

  • un dossier public/mods/<id>/ : le fichier du mod, un README.md court, une capture ;
  • sa ligne dans public/mods/mods.json : nom et description en français et en anglais, auteur, version (la même que dans le fichier du mod).

Les règles : pas de réseau (aucun fetch, aucun script venu d’ailleurs), pas de vraie personne nommée, pas de code minifié (il doit se relire), et npm test passe. Chaque mod est relu en entier avant d’entrer dans la liste. Le détail est dans CONTRIBUTING.md.

A first mod

A mod is a JavaScript file. It registers with the game through IdleBabel.registerMod, then plugs into its hooks: moments of the game where it gets called. This one doubles the reading of every method: 

IdleBabel.registerMod('double-reading', {
  version: '1.0.0',
  init() {
    // Every time production is computed: ×2.
    IdleBabel.registerHook('reading', () => 2);
    IdleBabel.notify('Double reading', 'Methods read twice as fast.');
  },
});

Save it as double-reading.js, put it online (see below), and load it in the game.

Loading it

In the game, open the options notebook, page Mods (after Save). “Mod list” shows the game’s mods, with their description: “Add” takes one. For any other, “Add a mod by its address” and paste its address, for instance: 

https://counteraccro.github.io/IdleBabel/mods/sans-mimic/sans-mimic.js

The mod loads right away, then on every visit, in the order they were added; it shows on the Mods page. Unticking it disables it (it stays in the list, no longer loaded); “delete” removes it. Either one reloads the page: a code mod cannot be undone mid-game. The list is kept in the save (and in its export).

To try things while you write, the browser console is enough: IdleBabel.loadMod('https://…').

Hosting it

You need an address that serves the file as JavaScript (or JSON). What works:

  • GitHub Pages: a repository with Pages enabled, the file at its root: https://your-name.github.io/your-repo/my-mod.js.
  • jsDelivr, in front of a public GitHub repository, nothing to set up: https://cdn.jsdelivr.net/gh/your-name/your-repo/my-mod.js.
  • A Gist: jsDelivr only serves repositories; for a Gist, use a repository instead.
GitHub’s “raw” addresses (raw.githubusercontent.com, gist.githubusercontent.com) serve the file as plain text: the browser refuses to run it. They work for a .json mod, not for a .js one.

The API: window.IdleBabel

NameWhat it does
registerMod(name, { version, init, save, load, options, onOptions }) Registers the mod. version: a string (“1.0.0”), shown in the notebook next to its name. init(): once, when it loads; this is where hooks go. save(): returns a string, kept in the game’s save. load(text): called right after init, with what save() returned last time. options and onOptions: see options. All are optional. Returns false if the name is empty or already taken.
registerHook(hook, function)Plugs a function into a hook.
stateThe game, readable and writable (see below).
notify(title, text)A notice at the bottom of the screen that fades on its own (text, not HTML).
addSeal({ id, name, text, reached }) A seal of your own, on a “Mods” plate of the strange book. name and text: a string, or { fr, en }. reached(state): returns true once it is reached (checked at every step of the game). It takes the name of the mod adding it: call it in init.
format(number)A number written in the player’s chosen notation (“1.23 million”…).
localeThe game’s language: 'fr' or 'en'.
gameWhat the game computes (production, prices, Ether, letter, Mimic), read-only: see below.
option(mod, id)The value of a mod’s option, set in the notebook (options); undefined if it does not exist.
loadMod(address)Loads another mod (returns a promise: true if it loaded).
replaceHeldBook(book => ({ root, update })) Replaces the open book at the bottom of the screen with your view (root, an HTML element), in the same place. The game keeps the page rhythm, the finds and the end of the book; update() is called at every leaf turned, by hand or on its own. book: index (the book’s number), page (the open leaf shows page and page + 1; 0: the book just arrived), pages (410), title, text(page) (returns { before, find, after }: find, the find, or empty) and turn() (turns a leaf, like a click). Ordinary books only: a rare book and the Great Book stay in 3D. One replacement only, the last one. Example: the e-reader.

A mod that throws does not crash the game: the error goes to the console, that hook is skipped, the rest goes on.

HookWhenThe function receivesIt returns

draw After every screen update (visible tab only). — —

A mod’s options

A mod declares its options in registerMod; the game draws them a page of the notebook, right after the “Mods” pages (one per active mod that has some), keeps them in the save (export included) and tells the mod when they change. The contents, on the notebook’s first page, lead there. Nothing to write for the notebook. 

IdleBabel.registerMod('my-mod', {
  version: '1.0.0',
  options: [
    // One choice among several: the chosen one is circled in pen.
    { id: 'size', name: { fr: 'Taille', en: 'Size' }, default: 'large',
      choices: [{ id: 'small', name: { fr: 'Petit', en: 'Small' } }, { id: 'large', name: { fr: 'Grand', en: 'Large' } }] },
    // Without choices: a checkbox (default true or false), with its pencil line.
    { id: 'block', name: { fr: 'Le bloc', en: 'The block' }, hint: { fr: 'En bas à gauche.', en: 'Bottom left.' }, default: true },
    // needs: greyed out while the “block” box is unchecked.
    { id: 'clock', name: { fr: 'L’heure', en: 'The time' }, default: true, needs: 'block' },
  ],
  // After init and load, with every value; then at each change in the notebook.
  onOptions(values) { console.log(values.size, values.block); },
});
IdleBabel.option('my-mod', 'size');   // 'large': the value, at any time

name, hint and a choice’s name: a string, or { fr, en }. A kept value that no longer means anything (option removed, choice renamed) goes back to its default; a malformed option is skipped (said in the console). The page shows the mod’s name, its version, then each option in the declared order.

What the game computes: IdleBabel.game

The game’s real formulas, read-only: a mod that shows numbers asks for them here rather than copying them (they change at every rebalance). Nothing here changes the game. Names are in the game’s language.

FunctionWhat it returns
methods()Each method: { id, name, owned, visible, nextCost, rate }. visible: found again, its seal is in the hive; nextCost: the price of the next copy (Economy of gesture and current boons included); rate: the pages per second of one more copy.
pagesPerSecond()The production, in pages per second.
intuitions()Each intuition of the white book: { id, name, level, maxLevel, nextPrice, visible, method }. nextPrice: in Knowledge, undefined at the end or while it cannot be understood; maxLevel: Infinity if endless; method: the id of the method it doubles at each level, otherwise null.
letterIn()Seconds before the next letter, or undefined while it is not drawn. The count only goes down on the game screen.
mimic(){ unlocked, here, every }: unlocked, here right now, and every how many seconds on average. It has no set time: every second, a small chance.
ether(){ gain, total, next }: the Ether a prestige would bring now, the pages read since forever, and those needed for one more Ether.

Each seal of the hive has data-method="<id>": a mod knows which hexagon is which method. The game touches no other data-* attribute of a seal: a mod may write there.

The game: IdleBabel.state

The whole state of the game, as it is saved. You can read it, and change it, at your own risk: the game checks nothing. The most useful fields:

FieldWhat it is
pagesPages in store (the ones you spend).
totalPagesReadPages read since the very beginning (never goes down).
toolsMethods owned: { diagonal: 12, finger: 3, … }.
knowledge, lifetimeKnowledgeKnowledge to spend; Knowledge found since the beginning.
ether, etherReceivedEther to spend; Ether received since the beginning.
booksFinished, bookPageBooks read to the end; the page of the book in hand.
stats.clicks, stats.playSecondsLeaves turned by hand; play time, in seconds.
exilesPrestiges done.
sealsSeals obtained, with their date.
settingsThe options notebook’s settings.
mods, modDataAddresses of the loaded mods; what each one saved.

To keep data of your own, use save / load rather than adding fields.

Mods without code (.json)

A .json file holds data only: it can do nothing but what the game allows, so it is safe. For now, it adds seals, each reached when a game counter gets to its value: 

{
  "id": "my-mod",
  "version": "1.0.0",
  "seals": [
    {
      "id": "million",
      "name": { "fr": "Un million", "en": "One million" },

Counters: pagesRead (since the beginning), booksRead, clicks, knowledge (since the beginning), ether (received), playSeconds, prestiges. Several in when: all are needed.

Mod seals have their own plate, at the end of the strange book. They count neither in the book’s progress nor in the finds bonus (+1% per seal): a mod does not skew the game that way.

The game’s mods, explained

No Mimic — sans-mimic.js

// The mod's name: the one the notebook shows, and the key of its data.
IdleBabel.registerMod('sans-mimic', {
  version: '1.0.0',
  // Called once, when it loads.
  init() {
    // Right before a Mimic appears, the game asks: returning false stops it.
    IdleBabel.registerHook('mimic', () => false);
  },
});

A Mimic already there stays: catch it, it gives back what it swallowed.

Letter catcher — attrape-lettres.js

IdleBabel.registerMod('attrape-lettres', {
  version: '1.0.0',
  init() {
    // Every letter escaping the book comes here.
    IdleBabel.registerHook('letter', (letter) => {
      // Let it rise for a second, then catch it, like a click.
      setTimeout(() => letter.catch(), 1000);
    });
  },
});

The letters of the word BABEL too: the whole word gets written.

E-reader — liseuse.js

IdleBabel.replaceHeldBook((book) => {
  // The view: a screen, and its right half that turns the leaf.
  const root = document.createElement('div');
  const next = document.createElement('div');
  next.addEventListener('click', () => book.turn());
  // A page: its gibberish, its find underlined (as text, never as HTML).
  const paragraph = (page) => {
    const { before, find, after } = book.text(page);
    const p = document.createElement('p');
    p.append(before, ' ', Object.assign(document.createElement('u'), { textContent: find }), ' ', after);
    return p;
  };
  // Called at every leaf turned: the screen is rewritten.
  const update = () => root.replaceChildren(paragraph(book.page), paragraph(book.page + 1), next);
  update();
  return { root, update };
});

The real file adds the casing, the title, “Pages 12–13 of 410”, the progress bar, a new book’s title page, and a font that shrinks so both pages fit on the screen.

BetterBabel — better-babel.js

Reading aids, like Cookie Monster for Cookie Clicker: each method of the hive takes the colour of its rank, and a block at the bottom left gives the next letter, the Mimic, the next Ether, the intuitions you can afford. Its nine options have their page in the notebook. The key parts: 

// A method's rank: waiting + payback of one copy, the smallest wins.
const production = IdleBabel.game.pagesPerSecond();
const score = (m) => Math.max(0, m.nextCost - IdleBabel.state.pages) / production + m.nextCost / m.rate;
const ranked = IdleBabel.game.methods().filter((m) => m.visible).sort((a, b) => score(a) - score(b));
// The colour: its own attribute on the seal, and its styles (the game never touches it).
for (const seal of document.querySelectorAll('.method-seal[data-method]'))
  seal.dataset.betterRank = ranked.findIndex((m) => m.id === seal.dataset.method);
// The next Ether: the missing pages ÷ the pace of the last minute.
const { total, next } = IdleBabel.game.ether();
// The Mimic has no set time: its average, and the chance to see it within 10 min.
const { every } = IdleBabel.game.mimic();
const chance = 1 - Math.exp(-600 / every);

The block is placed in the screen’s footer (draw hook, once a second); the pace is measured on the tick hook, hidden tab included. Its limits: the rank is for one copy, even when buying ×10; it ignores what a purchase unlocks without pages (the sentence at 25 copies, seals).

A mod that keeps data

let words = 0;
IdleBabel.registerMod('word-count', {
  version: '1.0.0',
  init() {
    IdleBabel.registerHook('find', (find) => {
      if (find.kind === 'word') words += 1;
    });
    IdleBabel.addSeal({
      id: 'hundred-words',
      name: { fr: 'Cent mots', en: 'A hundred words' },
      text: { fr: 'Trouve cent mots avec ce mod', en: 'Find a hundred words with this mod' },
      reached: () => words >= 100,
    });
  },
  // Kept in the game's save, given back to load() on the next visit.
  save: () => String(words),
  load: (text) => { words = Number(text) || 0; },
});

What a mod changes to the game

When the first mod loads, the game is marked, forever, even if the mod is removed later. Nothing else: the game goes on as before. Where it shows is for you to find.

A code mod can do anything: change the game, break it, read what the page shows. Only load mods you trust: those of the game’s list (reviewed before getting in) or those whose code you have read.

Proposing a mod for the game’s list

Mods from the list are added from the notebook, no address to paste: the game serves them itself. To propose yours, open a pull request on the game’s repository with:

  • a folder public/mods/<id>/: the mod’s file, a short README.md, a screenshot;
  • its line in public/mods/mods.json: name and description in French and English, author, version (the same as in the mod file).

The rules: no network (no fetch, no script from elsewhere), no real person named, no minified code (it must be readable), and npm test passes. Every mod is read in full before it enters the list. Details in CONTRIBUTING.md.
